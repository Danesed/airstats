# Security Policy

## Supported versions

Only the latest release gets security fixes. Î¼Stats updates itself
through Sparkle, so a fix ships as a normal release.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
GitHub's private security advisories on the repository.

Include the Î¼Stats version, your macOS version, and steps to reproduce.
I'll reply within a week, and I'll credit you in the release notes
unless you'd rather not be named.

## Scope

- The Î¼Stats app and its source in this repository
- The update feed in the GitHub releases and its EdDSA signatures
- The signed, notarized DMG on GitHub Releases
